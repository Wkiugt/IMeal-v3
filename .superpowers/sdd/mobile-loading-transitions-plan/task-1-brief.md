# Task 1 — Shared brand and motion surface

Create `apps/mobile/src/ui/BrandMotion.tsx`; no equivalent shared mobile component exists. Keep the implementation on React Native core `Animated`, the existing `react-native-svg` dependency, `theme`, and `useReducedMotion`; add no animation dependency.

Export `BrandMark({ size = 28, containerSize = 56, style }: { size?: number; containerSize?: number; style?: StyleProp<ViewStyle> })`. Draw the exact two paths and `viewBox="0 0 24 24"` from `docs/System-design-UI/assets/icons/brand-mark.svg` with `Svg`/`Path`, `fill="none"`, `stroke={theme.colors.accentDeep}`, `strokeWidth={1.6}`, round caps, and round joins. Render it in the existing accent-soft rounded badge so login and loading use one canonical mark rather than screen-local `Utensils` markup.

Export `BrandLoader({ label, compact = false }: { label: string; compact?: boolean })`. Render `BrandMark` plus visible label text and `accessibilityRole="progressbar"`. With normal motion, use `Animated.loop` around two consecutive 450 ms `Animated.parallel` steps with `Easing.inOut(Easing.cubic)` and `useNativeDriver: true`: opacity/scale move `0.6/0.96 → 1/1.04 → 0.6/0.96`. Stop the loop and both values during cleanup. With Reduce Motion, render the mark statically at opacity/scale `1` and start no loop. `compact=false` is centered full/section loading with a 56 px badge; `compact=true` is an inline 36 px badge for employee status and QR placeholder.

Export `StateTransition({ stateKey, children, style }: { stateKey: string; children: React.ReactNode; style?: StyleProp<ViewStyle> })`. On mount and each `stateKey` change, stop the previous animation, reset opacity to `0` and vertical offset to `8`, then animate both to `1`/`0` over 200 ms with `Easing.out(Easing.cubic)` and `useNativeDriver: true`. Reduce Motion skips the animation and sets final values synchronously. Stop animations in effect cleanup so rapid state replacement or unmount cannot finish a stale callback.

Export `ScreenEntrance({ active, children, style }: { active: boolean; children: React.ReactNode; style?: StyleProp<ViewStyle> })`. When `active` becomes true, run the same 200 ms fade/8 px entrance; when it becomes false, stop motion but leave final values visible until the next focus entry. Reduce Motion remains instantaneous. This avoids changing route state or unmount policy while giving mounted tabs a consistent visual entrance.

Use repository conventions and TypeScript. Do not edit App.tsx or screen files in this task; downstream integration consumes these exports. Do not add an animation dependency. Skip formatters, linters, and project-wide test suites. The mobile package has no configured test runner; run the narrowest relevant check available after implementation and report exact command/output.
