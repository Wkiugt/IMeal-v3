# Preview manifest

Focused review cards for the Meal Admin design system. Each file is a standalone HTML page that links `../colors_and_type.css` and renders live, not a screenshot.

| File                        | Covers                                                                                                            |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| `colors-primary.html`       | Core surfaces/text, accent scale, status pairs, elevation                                                         |
| `typography-specimens.html` | Font family roles, live type-scale samples                                                                        |
| `spacing-tokens.html`       | Observed spacing step scale, card padding rhythm, page gutters                                                    |
| `radius-shadows.html`       | Four-step radius scale, three-step shadow scale                                                                   |
| `components-buttons.html`   | Buttons, pills, avatars, toggle, form field, bar meter, data table, card                                          |
| `brand-assets.html`         | Brand mark + navigation icon set, loaded from `../assets/icons/`                                                  |
| `applied-surfaces.html`     | Real rendered screenshots from `../assets/screenshots/` showing the tokens composed into finished product screens |

Open any file directly in a browser — no build step required.
