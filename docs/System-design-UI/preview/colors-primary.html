Colors

All values are oklch(), read verbatim from the source prototypes' :root block. One accent hue, three depths, plus three status pairs.

Core surfaces & text

Neutral ground — near-white surface, blue-gray text, hairline borders.

--bg
oklch(100% 0 0)
--surface
oklch(100% 0 0)
--fg
oklch(27% 0.025 255)
--muted
oklch(44% 0.022 255)

Accent (single hue, three depths)

Used for exactly one primary action per view, plus active/selected indicators.

Status pairs
