Radius & Shadows

Four radius steps and three shadow steps, used consistently across both the mobile app and admin console — never an arbitrary value outside this scale.

Radius scale

Applied by role, not by component size.

--radius-sm · 14px
inputs, note boxes
--radius · 20px
nav items, icon wraps
--radius-lg · 28px
cards, buttons
--radius-pill
999px

Shadow scale

Shadows tint with --fg, not pure black.

--shadow-sm
resting cards
--shadow-md
hover / raised
--shadow-lg
modals, ticket, drawer
